# Краля — сайт на Vue с автоматической выгрузкой товаров из МойСклад

Каталог собран на Vue 3 (подключён через CDN, без сборки/Vite — проще
разворачивать). Небольшой сервер на Node.js подтягивает товары из
МойСклад и отдаёт их сайту. Ключ доступа хранится только на сервере —
в браузере он не виден.

## Структура фронтенда

```
public/
  index.html          — «скелет» страницы: подключает стили и вставляет секции
  css/style.css        — все стили сайта одним файлом
  sections/            — каждая секция сайта в своём файле
    header.html
    hero.html
    divider.html        — переиспользуемая лента-разделитель между секциями
    catalog.html
    about.html
    sizes.html
    contact.html
    location.html
    footer.html
  js/
    include.js          — подгружает секции из sections/ в index.html по порядку
    tape.js              — рисует деления на лентах-разделителях
    catalog.js            — Vue-приложение, которое рисует карточки товаров
```

`index.html` содержит только заготовки вида
`<div data-include="sections/catalog.html"></div>` — `include.js` при
загрузке страницы подставляет вместо каждой такой заготовки содержимое
нужного файла, сохраняя порядок секций. Если нужно поменять секцию —
редактируете конкретный файл в `sections/`, ничего больше трогать не нужно.

## Демо-товары

Пока в `.env` не указан доступ к МойСклад (или пока в нём ещё нет ни одного
товара), каталог не остаётся пустым — вместо этого показываются 3 примера
товара («Платье-рубашка», «Костюм с жакетом», «Шуба из эко-меха») с пометкой
«Показаны примеры товаров…» над фильтрами. Список примеров — в
`public/js/catalog.js`, константа `DEMO_PRODUCTS`. Как только сервер начнёт
отдавать реальные товары из МойСклад, эти карточки исчезнут сами — ничего
удалять вручную не нужно.

## Как это работает

1. Браузер открывает `public/index.html`, подгружает `css/style.css`
   и по очереди подставляет секции из `sections/` через `js/include.js`.
2. После того как все секции вставлены, `js/tape.js` рисует деления на
   лентах-разделителях, а `js/catalog.js` монтирует Vue-приложение на
   блок `#catalog-app` внутри `sections/catalog.html`.
3. Vue-приложение запрашивает `/api/products`.
4. Сервер (`server.js`) идёт в МойСклад API, забирает список товаров и цены.
5. Результат кэшируется на сервере (по умолчанию на час) — сайт не дёргает
   МойСклад при каждом визите посетителя.
6. Vue реактивно отрисовывает карточки товаров: пока грузится — показывает
   статус, если товаров нет или произошла ошибка — тоже сообщает об этом.

## Установка

1. Установите [Node.js](https://nodejs.org/) версии 18 или новее.
2. В папке проекта выполните:

   ```
   npm install
   cp .env.example .env
   ```

3. Откройте `.env` и заполните доступ к МойСклад — один из двух вариантов:
   - `MOYSKLAD_TOKEN` — токен доступа (Настройки → Обмен данными → API в МойСклад);
   - либо `MOYSKLAD_LOGIN` и `MOYSKLAD_PASSWORD` — логин и пароль от аккаунта.

4. Запустите сервер:

   ```
   npm start
   ```

5. Откройте в браузере `http://localhost:3000` — каталог подгрузится из МойСклад.

## Почему Vue через CDN, а не Vite-проект

Так сайт остаётся одним HTML-файлом, который отдаёт тот же Express-сервер —
не нужен отдельный шаг сборки (`npm run build`) и второй процесс для
разработки. Если позже понадобится более сложный интерфейс (личный кабинет,
фильтры, корзина) — эту же логику легко перенести в полноценный проект на
Vite + Vue, дайте знать, и я соберу такой вариант.

## Что ещё нужно донастроить

- В `public/sections/contact.html` замените `your_shop_username` на настоящий
  юзернейм вашего Telegram, а также ссылки WhatsApp / Instagram / почту.
  Тот же `your_shop_username` используется и в `public/js/catalog.js`
  (переменная `TELEGRAM_USERNAME`) — для кнопки «Заказать» на карточках товара.
- В МойСклад в поле «Описание» товара удобно писать состав ткани — он попадёт
  в карточку как подпись под названием.
- Категории в строке фильтров над каталогом берутся из групп товаров
  («Категория/Группа») в МойСклад — никакой отдельной настройки на сайте не
  нужно, всё подтягивается вместе с товарами. Товары без категории попадают
  в группу «Без категории».
- Клик по любой ссылке «Каталог» (в шапке, мобильном меню, кнопке в hero)
  открывает отдельную полноэкранную панель категорий
  (`sections/catalog-menu.html`). Пока в МойСклад не заведены категории,
  там показывается заготовка для обычного женского гардероба: «Платья»,
  «Костюмы», «Блузки и рубашки», «Юбки», «Верхняя одежда», «Шубы и дублёнки»,
  «Аксессуары». Как только у товаров появятся реальные категории — список
  на панели автоматически заменится вашими настоящими.
- На экранах уже 425px строка фильтров над каталогом (категории + поиск)
  прячется, вместо неё — одна кнопка «Категории», которая открывает ту же
  полноэкранную панель.
- Если товаров много, в `server.js` можно добавить постраничную загрузку
  (параметр `offset` в запросе к МойСклад).
- Фото товаров сейчас не подтягиваются — на карточках стоят условные
  иллюстрации. Если нужно — можно донастроить загрузку изображений через
  отдельный запрос `/entity/product/{id}/images`.

## Куда выложить сайт

Для сервера с Node.js подойдёт, например, Render, Railway или обычный VPS.
Статический хостинг вроде GitHub Pages не подойдёт — там нельзя запустить
`server.js`.
